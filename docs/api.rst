API Reference
=============

Every module in the ``traffic_sim`` package, documented from its docstrings.
The modules are ordered roughly as data flows through a run: the static world,
the vehicles on it, the step loop, and the pluggable policies (routing,
signals, right-of-way), then diagnostics and rendering.
